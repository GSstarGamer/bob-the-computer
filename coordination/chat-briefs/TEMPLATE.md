# Chat Brief Template

## Title

Short, specific task title.

## Stage

Which stage this chat belongs to.

## Purpose

The exact thing this chat is trying to finish.

## Read First

List the files Codex must read before doing anything.

## Allowed To Modify

List the files or folders that this chat may edit.

## Do Not Modify

List anything that should stay untouched.

## Deliverables

List the artifacts this chat should leave behind.

## Done When

Define what counts as complete.

## Notes For Next Chat

Capture the clean handoff and next recommended step.
