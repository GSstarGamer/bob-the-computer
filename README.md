# Bob Project Workspace

This repository is the file-driven workspace for the Bob project.

Bob is a multi-agent software builder system where Bob is the main agent and personality, and worker agents handle specialized responsibilities such as research, planning, coding, verification, website updates, and responses.

The project is organized so each Codex chat can stay narrow, stage-based, and easy to continue later.

## Workspace Layout

- `docs/`: Long-term project knowledge and design decisions.
- `coordination/`: Current stage, priorities, task tracking, blockers, and chat handoffs.
- `bob-core/`: Main application and orchestration code.
- `bob-site/`: Website and blog content.
- `bob-sandbox/`: Scratch work, prototypes, and experiments.

The workspace has been initialized with Stage 0 planning and coordination files. The next step is to move into a focused Stage 1 chat to build the actual repo and folder scaffolding in more detail.
